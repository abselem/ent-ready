# Коды подтверждения через Brevo на Railway

Backend отправляет письма через HTTPS API Brevo, без SMTP-портов.

1. Создайте аккаунт Brevo и завершите проверку/активацию отправки транзакционных писем, если её запросит сервис.
2. В разделе отправителей добавьте свой email и подтвердите его кодом из письма. Для старта можно использовать личный адрес; Brevo может заменить отправителя своим техническим доменом при отправке с бесплатных/неподтверждённых доменов. Доставка реальных писем зависит от одобрения аккаунта и правил Brevo.
3. Создайте **API key** в разделе SMTP & API → API Keys. SMTP key для этой интеграции не подходит.
4. В Railway → backend service → Variables добавьте:

```dotenv
BREVO_API_KEY=<ключ из Brevo>
BREVO_FROM_EMAIL=<подтверждённый email отправителя>
BREVO_FROM_NAME=ENT Ready
APP_ENV=production
OTP_DEMO_MODE=false
```

Для текущего проекта выбран отправитель `abselem.2001@gmail.com`: после его подтверждения задайте `BREVO_FROM_EMAIL=abselem.2001@gmail.com`.

Секретный ключ задавайте только в Railway, не в GitHub и не в сообщениях чата.

5. Примените изменения и перезапустите/redeploy backend с версией кода, поддерживающей Brevo.
6. Запросите код на сайте, проверьте папку «Спам» и Transactional → Logs в Brevo. Успех API означает принятие письма провайдером, а не гарантированную доставку в папку «Входящие».

При заданном `BREVO_API_KEY` приоритет: **Brevo → Resend → SMTP → локальные логи только в development/test**. Оставшийся `RESEND_API_KEY` не мешает переключению на Brevo. При ошибке отправки автоматического перехода на другой провайдер нет. Неполная настройка Brevo (ключ без корректного email) блокирует запуск с понятной ошибкой. При исчерпании квоты/отказе провайдера интерфейс сообщает об ошибке отправки.

Без ключа и подтверждённого отправителя реальную доставку проверить нельзя. Автотесты используют локальный HTTP-сервер и не отправляют письма.

Источники: [Brevo API](https://developers.brevo.com/reference/send-transac-email), [правила отправителей](https://help.brevo.com/hc/en-us/articles/14925263522578-Comply-with-Gmail-Yahoo-and-Microsoft-s-requirements-for-email-senders).
