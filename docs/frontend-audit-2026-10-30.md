## Оставшиеся ограничения

- Для завершения браузерного E2E нужны разрешённые тестовые аккаунты обеих ролей и материалы. Создание/редактирование/загрузка файлов, клавиатурный проход всех форм, 768/1440 px и светлая тема в реальном браузере ещё не подтверждены. Это не полный аудит соответствия WCAG.
- Нет отдельного UI «Забыли пароль», хотя API восстановления существует. Это функциональный пробел, не добавленный в рамках исправлений проверки.
- Авторизация между вкладками автоматически не синхронизируется.
- Возобновление обычного теста после перезагрузки отсутствует; ЕНТ восстанавливает сохранённые ответы. Источник истины времени — сервер.
- Предупреждение о несохранённых ответах работает для меню и закрытия/перезагрузки; браузерный Back внутри SPA отдельно не перехватывается.
- Баллы/активность профиля backend учитывают обычные тесты отдельно от ЕНТ; не объявляются общей метрикой всей подготовки.
- OTP 0000 по предыдущему явному запросу владельца остаётся временно включённым; эта проверка его не отключала.
