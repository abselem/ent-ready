# Создание уроков из шагов

Внедрён первый совместимый этап редактора по модели уроков Stepik: отдельные шаги, выбранный редактор и общий ученический просмотр. Это основа, а не полная копия функций Stepik.

## Работа преподавателя

1. Откройте «Уроки» → создание урока, введите название. Создаётся неопубликованный приватный черновик.
2. В редакторе нажмите «Добавить шаг»: Текст, Изображение, Код или Заметка.
3. Выбирайте шаги в списке слева (на телефоне список раскрывается над редактором). Каждый шаг редактируется отдельно; черновики не теряются при переключении и обновлении запросов.
4. Сохранение показывает состояния изменений, записи и ошибки. «Сохранить всё», «Предпросмотр» и публикация дожидаются записи всех изменённых шагов. При ошибке остаётся черновик и сообщение о проблемном шаге.
5. Порядок меняется доступными с клавиатуры кнопками; удаление подтверждается с номером шага. После удаления выбирается соседний шаг.
6. Предпросмотр использует тот же компонент содержимого, что ученик. Выбранный шаг сохраняется в URL `?step=<blockId>` и при возврате в редактор.
7. Перед публикацией выбирается аудитория существующими настройками. В опубликованном уроке сохранённые правки сразу видны ученикам; отдельной версии черновика опубликованного урока пока нет.

Ученику показан один шаг, номера шагов, переходы «Назад/Далее». Отметки завершения и процент прохождения не выдумываются: серверный прогресс по шагам ещё не реализован.

## Совместимость и API

- Один существующий `lesson_block` соответствует одному шагу. Старые уроки не конвертируются, данные не удаляются. Поддержаны прежние типы `text/code/image/note`; неизвестный старый тип отображается безопасным текстом.
- Сохранены маршруты, правила доступа, публикация, выдача доступа и просмотры. Новых зависимостей и миграций нет.
- Порядок отправляется полным списком `{order:[{id,order_num}]}`, позиции `0..N−1`. Сервер проверяет владельца урока, точный состав шагов, уникальные ID/позиции и записывает порядок транзакционно.
- Добавление шага и перестановка сериализуются блокировкой урока; параллельное добавление не создаёт одинаковых позиций.
- Ошибки чтения/удаления больше не маскируются успешным ответом. Изображения используют проверенные HTTP(S) или относительные `/static/` URL; произвольный HTML и iframe не исполняются.

## Проверки

- Frontend: 36/36 автоматических тестов. Новые проверки общего renderer: экранирование HTML, формулы, код, безопасные URL изображений, сохранение старого содержимого и сортировка без изменения кеша.
- Production-сборка frontend и TypeScript успешны; backend Docker-образ также собран.
- Полный ESLint: 0 ошибок, 7 предупреждений. Дополнительно scoped TypeScript/ESLint редактора и общего просмотрщика прошли.
- `go test ./...` и `go vet ./...` успешны на отдельном PostgreSQL. Новые проверки: права, неверный/чужой/неполный порядок, откат при ошибке второй записи, повтор перестановки и параллельное добавление.
- Независимое ревью сохранения/публикации и контрактов. Исправлены потеря выбранного шага при предпросмотре и относительные URL старых изображений.
- `git diff --check` успешен. Реальный браузерный проход обновлённого редактора не выполнен: ранее сохранённая политика блокирует просмотр localhost. Не объявляется проверкой WCAG или полным E2E.

## Что дальше

Видео, задания с проверкой ответов, баллы и структура «курс → модуль → урок» в этот этап не включены: объём был вынесен отдельным вопросом владельцу, ответ не получен. Для заданий нужен отдельный серверный контракт: правильные ответы нельзя помещать в публично выдаваемое содержимое блока. Текст сейчас обычный с формулами, без полноценного визуального форматирования как в Stepik.

Изменения этого этапа и предыдущего аудита сохранены в рабочей копии. Commit/push и обновление Railway в этой итерации не выполнялись. После локального обновления открыть редактор можно по адресу http://localhost:3000/teacher/lessons.

Основания: [создание урока Stepik](https://help.stepik.org/article/54788), [структура курса](https://help.stepik.org/article/54789), [добавление шагов](https://help.stepik.org/article/54791).
