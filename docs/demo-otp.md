# Временный режим OTP 0000

По запросу владельца тестового сайта включён временный режим для всех email: коды регистрации, входа по email и восстановления пароля равны `0000`. Письма не отправляются, ключи Brevo/Resend не требуются.

Режим включён по умолчанию, включая Railway, если `OTP_DEMO_MODE` не задан. Явно включить: `OTP_DEMO_MODE=true`. Это временная настройка до запуска сайта с реальными пользователями: любой, кто знает email, может запросить тестовый код для входа или восстановления.

Порядок работы прежний: сначала нажмите «Получить код», затем введите `0000`. Сохраняются проверка существования email, назначение кода, срок 15 минут, лимиты запросов/попыток и одноразовое использование. Код без предварительного запроса не принимается. Ранее запрошенные случайные коды не заменяются: запросите новый код после обновления backend.

Чтобы вернуть настоящие письма:

1. Настройте провайдера по [инструкции Brevo](brevo-railway.md).
2. В Railway → backend → Variables задайте `OTP_DEMO_MODE=false`.
3. Примените изменения и перезапустите backend.

При отключении demo используются случайные коды и прежняя проверка настройки провайдера. Активные ранее выданные коды живут до истечения срока, поэтому перед реальным запуском дождитесь 15 минут после остановки demo-выдачи (или отдельно отзовите тестовые коды).
